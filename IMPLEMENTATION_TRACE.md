## Verification Strategy

1. **Deterministic Unit Tests (`tests/`):** Write independent unit tests that mock input parameters (such as distance, speed, and actions) and evaluate the environment modules mathematically to prove they match the guide formulas exactly.
2. **Step-by-Step Logging:** Track the state transitions of a single vehicle over a 10-step episode and manually verify against theoretical hand-calculations.
3. **Reproducibility Runs:** Run a fast trial evaluation on a low number of steps (e.g. 10 episodes) to check that file structures, metrics, and JSON schemas are correctly exported.
